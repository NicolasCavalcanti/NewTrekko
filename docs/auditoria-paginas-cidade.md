### Problemas transversais (afetam todas as páginas, corrigir com template):
1. **FAQ genérico** — respostas tipo "consulte a ficha" são penalizadas pelo Google (thin content)
2. **Depoimentos idênticos** em todas as páginas — mesmo texto, não há diferenciação
3. **Meta description** — padrão único, sem palavras-chave de cauda longa por cidade
4. **Sem intro de cidade** — Google prioriza conteúdo que responde intenção de busca local
5. **Palavra-chave** — nenhuma página tem otimização para variações de cauda longa ("como chegar a X", "melhor época para X", "guia para trilha X")
